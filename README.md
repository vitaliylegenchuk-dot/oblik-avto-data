# oblik-avto-data

Відкриті дані для застосунку «Облік авто».

## fuel.json

Середні ціни на пальне по Україні (грн за літр). Оновлюються щоп'ятниці.

- `updated` — дата, на яку зібрано ціни
- `checked` — коли перевіряли востаннє
- `prices` — поточні ціни: `a100` (А-100), `a95p` (А-95 преміум), `a95`, `a92`, `dp` (дизель), `gas` (автогаз)
- `a100` — дата й джерело ціни А-100 (середня по великих мережах, бо Мінфін її не рахує)
- `history` — ціни по тижнях (до 104 записів)
- `source`, `source_url` — звідки взято цифри

Застосунок читає файл за адресою:
https://raw.githubusercontent.com/vitaliylegenchuk-dot/oblik-avto-data/main/fuel.json

## weather.json

Погода й небезпеки на дорогах для 27 міст (обласні центри та кілька великих міст). Оновлює бот GitHub Actions кожні 3 години (`scripts/weather.py`). Джерело — Open-Meteo.

- `places[]` — місто: `id`, `n` (назва), `ob` (область), `now` (зараз), `days` (3 дні), `hours` (24 год, кожні 2 год), `haz` (небезпеки на добу)
- `haz[]` — `k` (ice, snow, fog, wind, storm, rain, frost, heat), `lvl` (1–3), `t` (назва), `x` (порада), `from`, `when`

## signs.json

Каталог дорожніх знаків України (крім основних, вбудованих у застосунок). Застосунок завантажує його на вимогу кнопкою «Показати всі знаки».

- `signs[]` — `n` (номер за ДСТУ 4100:2021), `g` (група), `t` (назва українською), `svg` (зображення)
- Зображення: Wikimedia Commons (суспільне надбання), через пакет @road-signs/ua (MIT)
